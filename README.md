# 💩 La Caca Fea y el Gran Inodoro 🚽

**Un juego de aventuras y laberintos, con mucho humor, rollos de papel higiénico malvados y música de 8 bits.**

En esta aventura, **Caca Fea** quiere dejar de estar mugrienta, ponerse unos anteojos oscuros, verse espectacular y, finalmente, llegar al inodoro. Pero los papeles higiénicos no van a ponérselo tan fácil.

## 🎮 Cómo jugar

1. 🧼 **Juntá todos los jabones** del laberinto para limpiarte.
2. 🕶️ **Encontrá los anteojos oscuros** para ganar estilo.
3. 🪞 **Llegá al espejo** y transformate en una caca fachera.
4. 👑 **Derrotá al jefe** lanzándole burbujas de jabón. La marca amarilla **«¡JEFE!»** muestra desde el principio dónde aparecerá.
5. 🚽 **Entrá al inodoro** una vez que hayas vencido al jefe para pasar al siguiente nivel.

¡Cuidado! Los rollos de papel higiénico que recorren el laberinto pueden sacarte vidas.

## ✨ Qué incluye

- **4 laberintos**, cada uno con su propio jefe final.
- **Jefes móviles** que persiguen al protagonista y se vuelven más rápidos en cada nivel.
- **Burbujas de jabón** como arma, con indicación visual de los golpes acertados.
- **Música original de estilo 8 bits**: cambia de exploración a combate cuando aparece el jefe.
- **Diseño colorido de baño-cartoon**, con azulejos turquesas, controles táctiles y efectos cómicos.
- Funciona en **computadoras y celulares**, directamente desde el navegador.

## 🛠️ Ejecutar o publicar

El juego está hecho con **HTML, CSS y JavaScript**, sin dependencias externas. Todo está incluido en un único archivo.

**Para jugar localmente:** abrí `index.html` en un navegador.

**Para publicarlo en GitHub Pages:**

1. Subí `index.html` y este `README.md` a la raíz del repositorio.
2. En GitHub, entrá en **Settings → Pages**.
3. Elegí **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guardá la configuración y abrí la dirección que te indique GitHub Pages una vez publicada.

Si descargaste una versión con nombre como `caca_fea_v5.html`, **renombrala a `index.html`** antes de subirla.
